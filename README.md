# Snake Water Gun Game 🐍💧🔫

A simple Snake Water Gun game built using Python.

## Features

- Player vs Computer
- Random computer choices
- Input validation
- Win/Loss/Tie detection

## Concepts Used

- Python dictionaries
- if/elif/else
- User input
- random module
- f-strings

## How to Run

Run the `snake_water_gun.py` file using Python.
